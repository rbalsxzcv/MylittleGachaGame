# Tiny Gacha

가로 화면용 작은 캐릭터 수집 가챠 게임입니다. 빌드 과정 없이 HTML/CSS/JS(ES 모듈)만으로 동작하고, GitHub Pages에 그대로 올릴 수 있습니다.
비상업 개인 프로젝트이며 결제나 수익화 요소는 없습니다.

## 로컬에서 실행하기

`index.html`을 더블클릭해서 열면 동작하지 않아요(`file://`에서는 ES 모듈과 `fetch`가 막힘). 아래 둘 중 하나로 **로컬 서버**를 띄워 주세요.

**방법 1: Python (권장)**

```bash
# 저장소 폴더에서
python -m http.server 8000
```
브라우저에서 http://localhost:8000 을 엽니다. 종료는 터미널에서 `Ctrl + C`.

**방법 2: VS Code 확장 "Live Server"**
확장을 설치한 뒤 `index.html`을 우클릭하고 **Open with Live Server**를 누릅니다.

### 휴대폰 화면으로 확인하기
크롬 개발자 도구(F12) → 왼쪽 위 기기 아이콘(Toggle device toolbar) → 가로 크기(예: 844×390)를 선택합니다.
세로로 바꾸면 "기기를 가로로 돌려주세요" 안내가 나와야 정상입니다.

### 개발용 콘솔 명령 (localhost에서만)
| 명령 | 설명 |
|---|---|
| `__tg.simulate(100000)` | 10만 번 뽑기 시뮬레이션 (세이브에 영향 없음) |
| `__tg.addGems(10000)` | 테스트용 보석 추가 |

천장과 10연 확정 때문에 실제 SSR 비율은 3%보다 조금 높게(약 3.9%) 나오는 게 정상입니다.

## 조작
| 키 | 동작 |
|---|---|
| G / C / O | 뽑기 / 도감 / 설정 |
| F | 전체화면 |
| Esc, Backspace | 뒤로 / 팝업 닫기 |
| 1 / 0 | (뽑기 화면) 1회 / 10회 뽑기 |
| Space, Enter | (결과 화면) 다음 카드 |
| A / S | (결과 화면) 모두 열기 / 건너뛰기 |
| ← / → | (홈) 배너 넘기기 |

터치 기기에서는 모든 기능을 탭으로 사용할 수 있어요.

## 캐릭터 추가하기
`data/characters.json`에 항목을 추가합니다.

```json
{
  "id": "sr_newchar",
  "name": "새 캐릭터",
  "rarity": "SR",
  "title": "칭호",
  "description": "소개 문장",
  "image": "assets/chars/sr_newchar.png",
  "addedAt": "2026-12-01T00:00:00+09:00"
}
```
- `id`: 영문, 숫자, `_`, `-`만 사용. 한 번 정하면 바꾸지 마세요(세이브가 id로 기록됨).
- `rarity`: `R`, `SR`, `SSR` 중 하나.
- `image`: 배경이 투명한 PNG(긴 변 512px). 없거나 경로가 틀리면 희귀도 색 카드로 대신 표시돼요.
- 잘못된 항목은 건너뛰고 나머지는 정상 동작해요. 문제 원인은 브라우저 콘솔(F12)에 표시됩니다.
- 새로 추가된 캐릭터는 플레이어 도감에 **NEW**로 표시돼요.

## 폴더 구조
```
index.html, style.css, manifest.webmanifest
js/
  main.js          시작점 (데이터 → 세이브 → 화면)
  core/            스테이지 크기 조정, 데이터 로더, 세이브, KST 시간, 난수, 이벤트
  systems/         게임 규칙 (재화, 가챠, 도감) — 화면과 분리됨
  ui/              화면들 (홈, 뽑기, 결과, 도감, 설정)과 공용 부품
data/              게임 데이터(JSON)
assets/            chars/(캐릭터), banners/(배너), bg/(배경), icon.svg
dev/               (Phase 2) 로컬 전용 관리 도구 — 비밀 키는 커밋 금지
```

## 게임 규칙 요약
- 1회 100 보석, 10회 1,000 보석 / 확률 R 79% · SR 18% · SSR 3%
- 50번째 뽑기까지 SSR이 없으면 50번째는 SSR 확정 / 10회 뽑기는 SR 이상 1장 확정
- 중복 캐릭터는 별 +1 (최대 5개)
- 첫 시작 보석 1,000개, 매일 첫 접속 시 300개 (한국 시간 자정 기준)
- 진행 상황은 브라우저(localStorage)에 저장돼요. 설정 → **세이브 코드**로 다른 기기로 옮길 수 있어요.

## GitHub Pages로 배포하기
1. GitHub 저장소 → **Settings → Pages**
2. Source: **Deploy from a branch**, Branch: `main` / `/ (root)` → Save
3. 잠시 후 `https://<아이디>.github.io/<저장소이름>/` 에서 열립니다.

모바일에서는 브라우저 메뉴의 **홈 화면에 추가**로 설치하면 전체화면으로 실행돼요.
